# Codex 项目内图片同步设计

## 目标

将 Steam 图片每日同步改由 Codex 在每天北京时间早上 11:00 直接执行，并保存到项目内可写目录 `D:\iwen-codex\codex-shop\data\images`。

## 运行方式

- Codex 定时任务在每天 11:00 读取 `C:\Users\33756\Desktop\自动化\游戏图片.xls` 的前 20 个有效游戏。
- 每个游戏保存封面、前 4 张截图和配置图到 `data\images\<游戏名>`。
- 定时任务仍使用本机代理检测及显式代理连接；单个游戏失败不影响后续游戏。
- Codex 任务完成后报告成功和失败数量。

## 移除的配置

- 删除 Windows 任务计划中的 `SteamImageDailySync`。
- 不再使用 `D:\图片` 作为自动同步目标。

## 验证

- 更新本地保存路径并确认目标目录可创建。
- 立即执行一次同步，确认日志包含实际结果且图片写入 `data\images`。
- 重新运行项目测试。
