# 每日封面编号设计

## 目标

新保存的游戏封面按当天全局顺序命名为 `01封面图.jpg`、`02封面图.jpg` 等；本机日期跨过 00:00 后，下一次保存重新从 `01` 开始。

## 行为

- 编号在所有游戏、所有保存文件夹之间全局共用。
- 手动保存与每日自动同步共用同一条编号序列。
- 仅当封面图被选中且下载成功时才消耗一个编号；截图和系统需求图不占用编号。
- 编号至少补齐两位；超过 99 后使用自然数字，例如 `100封面图.jpg`。
- 已存在的封面文件保持原样，不重命名、不移动、不删除。

## 实现

- 在 `data` 下维护一个小型 JSON 状态文件，保存本地日期与当前已分配的编号。
- 保存封面前读取状态；日期不同则将计数重置为零，再分配下一个编号。
- 通过状态锁文件串行化封面编号分配，避免网页保存与独立运行的自动同步进程同时运行时重复编号。
- 封面下载失败时不提交新计数；成功写入后再持久化计数。

## 验收

- 同一天连续保存两个不同游戏封面，文件名为 `01封面图.*`、`02封面图.*`。
- 仅保存截图或系统需求时，下一张封面编号不变。
- 模拟次日首次保存时，编号回到 `01封面图.*`。
- 原有封面文件不发生任何改动。
